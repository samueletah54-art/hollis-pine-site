# IMAGE-PROMPTS.md

Every image the site needs. Put the files in `public/images/` with **exactly** these names, then run `npm run build` (or restart `npm run dev`). The site only requests files that exist, so it works with any subset.

## Format

- WebP, 1600 px wide. Products: **4:5** (1600 × 2000). Banners: **16:9** (1600 × 900).
- Keep each file under 300 KB (quality 75–80). The site shows a blurred placeholder while it loads.

**Already supplied (5):** `fraser-fir`, `nordmann-fir`, `classic-full-prelit`, `farm-dawn-frost`, `delivered-netted-tree`. The prompts below still apply to the other photos so they match these.

## One style for every image

Add this to the end of **every** prompt so the whole site looks like one photoshoot:

> Natural window light from camera left, shot on a 50 mm lens, muted film colours with soft fine grain, a real home or a real farm in winter, no people's faces in close-up, no text, logos or signs in the image.
